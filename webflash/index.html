ESP Magic Eyes

Install or update the firmware straight from your browser. No software needed.

Install

  1. Plug in the boardConnect the ESP32 to this computer with a USB data cable.
  2. Click ConnectPick the board's serial port in the list that pops up.
  3. Choose InstallOn a new board, allow it to erase the device first.
Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer (phones and Firefox/Safari aren't supported). Web flashing only works on a secure (https) page.

No firmware is published here yet. Please check back later.

Works in Chrome and Edge on Windows, macOS, Linux and ChromeOS.

Update a device that's already set up

Help

No serial port shows up
  • Try another cable. Some USB cables only charge and can't carry data.
  • Install the USB driver for your board's chip, usually CP210x or CH340.
It hangs at "Connecting…"

Hold the board's BOOT button while you click Install, and let go once the progress bar starts.

What next, after installing?

The device starts a WiFi network named MagicEyes-Setup-XXXX (password eyes-setup). Connect to it to give the device your home WiFi details. The README has the full walkthrough.
