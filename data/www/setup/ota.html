Newest work in progress. It can be untested.

Uploading from PlatformIO over the network (pio run -t upload --upload-port <ip>) needs the admin password, if one is set: add upload_flags = --auth=<admin password> to platformio.ini. See Security.

Settings backup

Saves every setting — servo calibration, radar, LED, names — to a file on this computer. Restoring it on this or another Magic Eyes needs no new calibration.

The file then holds your WiFi password in plain text. Keep it somewhere safe.

Restore settings

Choose a settings file. Everything in it replaces the current settings, then the device restarts. If the file holds WiFi and passwords, the device joins that network and asks for those passwords.

Firmware update

Upload a compiled firmware .bin (app image). The device reboots automatically on success.

Filesystem update

Upload a LittleFS image to update just the web frontend/data, independently of the firmware. The device reboots automatically on success.
