Admin password—

Network (PlatformIO) updates are paused until the device restarts, so the new admin password can take effect.

Control password

Needed to open the web pages and move the eyes (manual control, gestures, play modes). Log in with user name user. The admin password also works here.

Admin password

Needed for these setup pages and for firmware updates. Log in with user name admin. While no admin password is set, the control password protects these pages too.

Updating from PlatformIO over the network then needs upload_flags = --auth=<admin password> in platformio.ini.

Forgot a password?

With the device in hand, either hold the BOOT button for 5 seconds (this also forgets the WiFi network and starts the setup access point), or type auth reset in the USB serial console. Both remove both passwords.
